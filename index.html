Privacy Policy

Golden Night — Smart gold dark mode for Chrome
Last updated: October 17, 2026
In short: Golden Night does not send page content or locally stored settings to us. It works locally in your browser. For monochrome-icon detection, it may make cookie-free requests for image files already referenced by a page.

1Data we collect

Golden Night does not collect or transmit your name, email address, page text, form contents, password values, cookies, precise location or device identifiers. It does inspect page colour/style values to apply dark mode. It does not send page content or locally stored settings to us. A website origin is stored locally only when you save a per-site choice, as described below.

2Data stored on your device

The extension stores these settings locally in Chrome's extension storage:

  • whether the extension is enabled or disabled;
  • your chosen interface language (English or Persian);
  • per-site choices, such as whether to darken a website or stop asking on that site;
  • the last requested state of the optional Chrome built-in dark-mode control and temporary restart/pending metadata.

These values remain in chrome.storage.local on your device and are not sent to Golden Night. Site-specific choices include the relevant website origins. The settings are removed when you uninstall the extension.

3What the extension does on web pages

When turned on, the extension runs on pages you open and maps bright page colours (such as white backgrounds and dark text) to dark-mode colours while leaving photos, videos and vivid colours as they are. To avoid darkening pages that are already dark, it checks computed colour/style values in the visible page. It also reads the website origin so a per-site choice can be remembered. Page text, form contents, passwords and cookies are not read for collection or transmitted.

Icons: to lighten only single-colour icons and leave coloured icons untouched, the extension may request the small image files (for example an icon sprite) that the page already references, then examine their pixels in memory. These requests go to the host used for that image and omit cookies; like any web request, the destination host may still observe ordinary connection metadata such as your IP address. The extension does not persist a separate copy in its own storage; Chrome may still apply its normal HTTP cache behaviour. The extension does not send these files or page content to Golden Night or an analytics service.

4Network, analytics and third parties

The extension includes no analytics, advertising, tracking SDKs or developer-operated backend. As described in section 3, monochrome-icon detection may make cookie-free requests for image resources already referenced by the page. The extension does not transmit page content or locally stored settings to Golden Night, and it does not download or run remote executable code. All executable extension code is included in the package.

5Permissions explained

  • storage — saves the two settings described above.
  • Access to all websites — required so dark mode can work on any site you visit, and so the extension's background worker can read the icon image files those pages use (section 3). No page data leaves your device.
  • scripting — lets the extension switch itself on in a tab that was already open when the extension was updated, without reloading it.
  • No other permissions (such as tabs, history, cookies or downloads) are requested.

The “Enable Chrome's own dark mode” button only opens chrome://flags in a new tab. It does not change any browser setting by itself.

6Sharing and selling data

There is no data to share or sell. Golden Night complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

7Children's privacy

The extension collects no data from anyone, including children.

8Changes to this policy

If this policy changes, the updated version will be published on this page with a new date.

سیاست حریم خصوصی

شب طلایی (Golden Night) — دارک مود هوشمند طلایی برای کروم
آخرین به‌روزرسانی: ۲۵ مهر ۱۴۰۵ (۱۷ اکتبر ۲۰۲۶)
خلاصه: شب طلایی محتوای صفحه یا تنظیمات ذخیره‌شده روی دستگاه شما را برای ما ارسال نمی‌کند و کارهای اصلی را محلی در مرورگر انجام می‌دهد. برای تشخیص آیکون‌های تک‌رنگ، ممکن است فایل‌های تصویری‌ای را که صفحه از قبل به آن‌ها ارجاع می‌دهد، بدون ارسال کوکی درخواست کند.

۱اطلاعاتی که جمع‌آوری می‌کنیم

شب طلایی نام، ایمیل، متن صفحات، محتوای فرم‌ها، مقدار رمزهای عبور، کوکی‌ها، موقعیت مکانی دقیق یا شناسه‌های دستگاه را جمع‌آوری یا برای ما ارسال نمی‌کند. افزونه برای اجرای دارک‌مود، مقدارهای رنگ و استایل صفحه را بررسی می‌کند. محتوای صفحه یا تنظیمات محلی برای ما ارسال نمی‌شوند. مبدأ هر وب‌سایت فقط زمانی در حافظهٔ محلی ذخیره می‌شود که ترجیح اختصاصی آن سایت را ثبت کنید؛ توضیح بیشتر در بخش بعد آمده است.

۲داده‌های ذخیره‌شده روی دستگاه شما

افزونه این تنظیمات را به‌صورت محلی در حافظهٔ افزونه‌های کروم نگه می‌دارد:

  • روشن یا خاموش بودن افزونه؛
  • زبان انتخابی رابط (فارسی یا انگلیسی)؛
  • انتخاب‌های اختصاصی هر سایت، مثل تیره‌کردن آن یا دیگر نپرسیدن برای همان سایت؛
  • آخرین وضعیت درخواستی برای کنترل اختیاری دارک‌مود داخلی کروم و اطلاعات موقت مربوط به انتظار برای راه‌اندازی مجدد.

این مقدارها در chrome.storage.local روی دستگاه خودتان می‌مانند و برای شب طلایی ارسال نمی‌شوند. انتخاب‌های اختصاصی سایت شامل مبدأ همان وب‌سایت هستند. این تنظیمات با حذف افزونه پاک می‌شوند.

۳افزونه روی صفحات وب چه می‌کند؟

وقتی روشن باشد، افزونه رنگ‌های روشن صفحه (مانند پس‌زمینهٔ سفید و متن تیره) را به رنگ‌های دارک‌مود تبدیل می‌کند و عکس‌ها، ویدیوها و رنگ‌های زنده را دست‌نخورده می‌گذارد. برای اینکه صفحه‌های از قبل تیره دوباره تیره نشوند، مقدارهای محاسبه‌شدهٔ رنگ و استایل بخش‌های صفحه را بررسی می‌کند. همچنین مبدأ وب‌سایت را می‌خواند تا انتخاب اختصاصی همان سایت را به خاطر بسپارد. متن صفحه، محتوای فرم‌ها، رمزهای عبور و کوکی‌ها برای جمع‌آوری خوانده یا ارسال نمی‌شوند.

آیکون‌ها: برای روشن‌کردن آیکون‌های تک‌رنگ و دست‌نخورده‌گذاشتن آیکون‌های رنگی، افزونه ممکن است فایل‌های تصویری کوچکی را که صفحه از قبل به آن‌ها ارجاع می‌دهد (مثلاً اسپرایت آیکون) درخواست کند و پیکسل‌های آن‌ها را در حافظه بررسی کند. این درخواست‌ها به میزبان همان تصویر فرستاده می‌شوند و کوکی ارسال نمی‌کنند؛ بااین‌حال، مانند هر درخواست وب، میزبان مقصد ممکن است فرادادهٔ عادی اتصال مانند نشانی IP شما را ببیند. افزونه نسخهٔ جداگانه‌ای از این فایل‌ها را در حافظهٔ خودش ذخیره نمی‌کند؛ بااین‌حال ممکن است کش معمول HTTP مرورگر طبق رفتار عادی کروم اعمال شود. افزونه این فایل‌ها یا محتوای صفحه را برای شب طلایی یا سرویس تحلیل‌گر ارسال نمی‌کند.

۴شبکه، ابزارهای تحلیل و اشخاص ثالث

افزونه ابزار تحلیل، تبلیغات، SDK ردیابی یا سرور پشتیبان تحت مدیریت سازنده ندارد. همان‌طور که در بخش ۳ توضیح داده شد، تشخیص آیکون‌های تک‌رنگ ممکن است باعث درخواست فایل‌های تصویری‌ای شود که صفحه از قبل به آن‌ها ارجاع می‌دهد؛ این درخواست‌ها بدون کوکی هستند. محتوای صفحه یا تنظیمات ذخیره‌شدهٔ محلی برای شب طلایی ارسال نمی‌شوند و افزونه کد اجرایی را از راه دور دانلود یا اجرا نمی‌کند. همهٔ کدهای اجرایی افزونه داخل بسته قرار دارند.

۵توضیح مجوزها

  • storage — برای ذخیره‌ی دو تنظیم بالا.
  • دسترسی به همه‌ی وب‌سایت‌ها — برای اینکه دارک مود روی هر سایتی که باز می‌کنید کار کند و سرویس‌ورکر افزونه بتواند فایل‌های تصویر آیکونی را که آن صفحه‌ها استفاده می‌کنند بخواند (بخش ۳). هیچ داده‌ای از صفحه از دستگاه شما خارج نمی‌شود.
  • scripting — برای اینکه افزونه بتواند خودش را در تبی که هنگام به‌روزرسانی افزونه از قبل باز بوده، بدون بارگذاری دوباره فعال کند.
  • هیچ مجوز دیگری (مثل تب‌ها، تاریخچه، کوکی‌ها یا دانلودها) درخواست نمی‌شود.

دکمه‌ی «فعال‌سازی دارک مود خود کروم» فقط صفحه‌ی chrome://flags را در یک تب جدید باز می‌کند و خودش هیچ تنظیمی از مرورگر را تغییر نمی‌دهد.
